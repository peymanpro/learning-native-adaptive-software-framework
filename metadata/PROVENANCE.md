# Publication Provenance Notes

This package is intended to preserve Version 0.1 of the LNASF technical disclosure as a dated, versioned artifact.

Suggested publication sequence:

1. Commit this exact directory to Git.
2. Create a release tag such as `v0.1.0`.
3. Keep the release immutable where the hosting service supports it.
4. Upload the same publication artifact to Zenodo and obtain a DOI.
5. Preserve the DOI, Git tag, commit hash, and SHA-256 manifest together in future records.
